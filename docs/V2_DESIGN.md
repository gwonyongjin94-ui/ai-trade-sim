# v2 설계: 6개국, 실제 국가를 빗댄 무역 게임 (2026-11-05 초안)

v1(두 가상 국가 A·B)의 시험판에서 AI 지도자들은 확전하지 않고 관세를 5%에 두었다. 이론상 균형 관세(150~200%)보다 훨씬 협력적이다. v2는 같은 질문(AI 지도자가 어떻게 행동하나)을 현실 국제 무역 구도에 가까운 무대에서 묻는다. v1 코드와 결과는 git 태그 `v1-two-country`에 남긴다.

## 정한 것 (사용자 결정, 2026-11-05)

| 항목 | 결정 |
|---|---|
| 나라 | A 대한민국 · B 중국·북한 · C 일본 · D 중동 국가들 · E 미국·캐나다·멕시코 · F 대만 |
| 나라 이름 | 실험 조건으로 비교: 실제 이름 판 / A~F 이름 판 (경제 수치는 둘 다 실제 데이터). WarAgent식 비교 |
| 관세·수출 통제 | 상대국별로 따로 매긴다 (나라당 품목 8개 × 상대 5개국) |
| 상대 이익 목표 | 나를 뺀 나라 중 실질 GDP가 가장 큰 나라와의 비율. 1위 나라에게는 2위와의 격차가 된다. 매 분기 다시 정한다 |
| AI 모델 | Claude Haiku 5.5 |

## 기본값으로 제안하는 것 (확인 필요)

| 항목 | 제안 | 이유 |
|---|---|---|
| AI 지도자 수 | 6개국 모두 AI | 한 나라만 규칙형이면 그 나라가 행동을 정해 버린다 |
| 호칭 | 모두 "지도자" | 중국·북한, 중동은 4년 임기 대통령제가 아니다 |
| 임기 | 4년(16분기) 한 판에 지도자 1명씩, 교체 없음 | v1 본 실험과 같다. 나라마다 다른 임기 규칙은 후속 실험 |
| 외교 | 특정 나라에 보내는 메시지 + 전체 공개 성명. 제안은 대상 나라를 지정(양자·다자) | 현실의 양자 협상과 다자 합의를 둘 다 담는다 |

| 이론 기준선 | 자유무역·현상 유지 먼저. 6개국 내시 균형은 계산량이 커서 나중에 | 변수 240개(6 × 8 × 5)의 균형 계산 |

## 바뀌는 코드

1. 엔진: 나라 N개, 상대국별 관세·통제, N개국 시장 균형(Armington), 실제 데이터 보정
2. 지도자 프롬프트: 나라 이름 조건, 6개국 상황표, 상대국별 정책표, 다자 외교
3. 약속·위반: 의무 나라와 대상 나라
4. 측정: 확전·보복·호응을 "누가 누구에게"로. 자기 인식·결과 인식은 그대로 쓴다
5. 보고서·기록부·규칙 이해도 검사
6. 웹 화면(사람 플레이)은 나중에

## 비용 (대략, 만든 뒤 계획 출력으로 다시 추정)

- 한 판 호출: 6개국 × 2라운드 × 16분기 = 192회 (v1은 64회)
- 프롬프트가 길어져 호출당 토큰도 늘어남 → 한 판 약 $0.4~0.8로 봄
- 유료 실행은 매번 계획과 비용을 보여 주고 허락받는다

## 진행 순서

1. 이 문서 확정
2. 데이터 수집 (허락받고 내려받기)
3. 엔진 N개국화 + 보정 + 테스트
4. 프롬프트·외교·약속
5. 측정·보고서
6. 규칙 이해도 검사 (Haiku, 몇 센트)
7. 시험판 1~2판 (허락받고)
