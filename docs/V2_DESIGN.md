# v2 설계: 6개국, 실제 국가를 빗댄 무역 게임 (2026-11-05 초안)

v1(두 가상 국가 A·B)의 시험판에서 AI 지도자들은 확전하지 않고 관세를 5%에 두었다. 이론상 균형 관세(150~200%)보다 훨씬 협력적이다. v2는 같은 질문(AI 지도자가 어떻게 행동하나)을 현실 국제 무역 구도에 가까운 무대에서 묻는다. v1 코드와 결과는 git 태그 `v1-two-country`에 남긴다.

## 정한 것 (사용자 결정, 2026-11-05)

| 항목 | 결정 |
|---|---|
| 나라 | A 대한민국 · B 중국·북한 · C 일본 · D 중동 국가들 · E 미국·캐나다·멕시코 · F 대만 |
| 나라 이름 | 실험 조건으로 비교: 실제 이름 판 / A~F 이름 판 (경제 수치는 둘 다 실제 데이터). WarAgent식 비교 |
| 관세·수출 통제 | 상대국별로 따로 매긴다 (나라당 물품 10개 × 상대 5개국) |
| 상대 이익 목표 | 나를 뺀 나라 중 실질 GDP가 가장 큰 나라와의 비율. 1위 나라에게는 2위와의 격차가 된다. 매 분기 다시 정한다 |
| AI 모델 | Claude Haiku 5.5 |
| 물품 | 10개로 다시 묶음 (아래 표). 8개로는 한국 교역의 53~68%만 담겨서 |
| 나머지 세계 | AI가 아닌 7번째 블록. 정책은 고정. 6개 블록 수출의 25~65%가 이쪽이라 빼면 교역이 크게 왜곡된다 |
| 시작 관세 | 현실 관세 (2022년 적용 관세 + 미중 무역전쟁 관세). 시작 수출 통제는 미국→중국 반도체 1단계, 나머지 0 |

## 데이터 (모두 공개 자료, 내려받기 전에 허락받음)

| 자료 | 출처 | 파일 |
|---|---|---|
| 블록 간 교역 2023 | UN Comtrade 공개 API. 수입국 신고값 우선, 없으면 수출국 신고값 | `data/v2/trade-2023.json` (`npm run data:v2`) |
| 나머지 세계와의 교역 | 각 나라의 대세계 교역 − 포함된 나라와의 교역. 중동은 World Bank 상품 무역 총액에서 추정 | 같은 파일 `rowFlows` |
| GDP·인구·노동력·소비·투자 | World Bank, 대만은 IMF WEO, 북한 GDP는 한국은행, 대만 노동력은 대만 통계청 | `data/v2/macro-2023.json`, `data/v2/manual-2023.json` |
| 문화 | Hofstede 6개 지표 (북한 자료 없음) | `data/raw/hofstede/` |
| 시작 관세 | World Bank WITS 적용 관세(AHS, 수입액 가중) 2022. 대만의 관세는 WITS TRAINS 최혜국 세율, 대만에 매기는 관세는 수입국의 최혜국 세율 (WITS에 대만이 상대국으로 없고, 대만과 FTA를 맺은 나라가 없음). 미중 관세는 PIIE(Bown) 평균으로 덧씌움 (미국→중국 19.3%, 중국→미국 21%). 나머지 세계의 관세는 EU 관세로 대신 | `data/v2/tariffs.json` (`npm run tariffs:v2`) |

알려진 한계: 홍콩·마카오·북한과 나머지 세계의 교역은 빠졌다(신고 자료 없음). 중동의 대세계 교역은 추정이다. WITS 품목군은 기계·전자를 나누지 않아 둘이 같은 관세로 시작한다. 반도체는 정보기술협정으로 0에서 시작한다. 미국 232조(철강·알루미늄) 관세는 넣지 않았다. 미중 관세는 물품마다 같은 폭으로 더했다 (미국 쪽 +16.3%p, 중국 쪽 +14.3%p). 멕시코의 쿠웨이트·이라크 관세는 자료가 없어 같은 블록 다른 나라 값을 쓴다.

## 바뀌는 코드

1. 엔진: 나라 N개 + 나머지 세계, 상대국별 관세·통제, N개국 시장 균형(Armington), 실제 데이터 보정
2. 지도자 프롬프트: 나라 이름 조건, 6개국 상황표, 상대국별 정책표, 다자 외교
3. 약속·위반: 의무 나라와 대상 나라
4. 측정: 확전·보복·호응을 "누가 누구에게"로. 자기 인식·결과 인식은 그대로 쓴다
5. 보고서·기록부·규칙 이해도 검사
6. 웹 화면(사람 플레이)은 나중에

## 비용 (대략, 만든 뒤 계획 출력으로 다시 추정)

- 한 판 호출: 6개국 × 2라운드 × 16분기 = 192회 (v1은 64회)
- 프롬프트가 길어져 호출당 토큰도 늘어남 → 한 판 약 $0.4~0.8로 봄
- 유료 실행은 매번 계획과 비용을 보여 주고 허락받는다
