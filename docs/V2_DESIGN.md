# v2 설계: 6개국, 실제 국가를 빗댄 무역 게임 (2026-11-05 초안)

v1(두 가상 국가 A·B)의 시험판에서 AI 지도자들은 확전하지 않고 관세를 5%에 두었다. 이론상 균형 관세(150~200%)보다 훨씬 협력적이다. v2는 같은 질문(AI 지도자가 어떻게 행동하나)을 현실 국제 무역 구도에 가까운 무대에서 묻는다. v1 코드와 결과는 git 태그 `v1-two-country`에 남긴다.

## 엔진 (2026-11-05, `src/v2/`)

v1 엔진(`src/engine/`)은 그대로 두고 새 폴더에 만들었다. v1 시험판·보고서는 계속 재현된다.

| 항목 | 내용 |
|---|---|
| 지역 | AI 블록 6개 + 나머지 세계 R (정책 고정: 관세는 EU 관세, 수출 통제 없음) |
| 부문 | 교역재 10개 + 교역되지 않는 서비스·건설 (사용자 결정: 중간재 없이 최종재만, 서비스는 넣음) |
| 교역 | Armington CES, 구매자마다 공급처 7곳. 관세·수출 통제는 상대국별 |
| 보정 | 시작 생산자 가격을 모두 1로 두고 2023년 관세·통제에서 자료가 그대로 나오게 가중치를 거꾸로 푼다 (표준 CGE 방식). 시작점은 정상상태 |
| 생산 | 총산출 = World Bank 부가가치 ÷ 부가가치율(가정: 농업 0.5, 광업 0.8, 제조업 0.3, 서비스 0.6). 묶음 안의 물품 구성은 세계 교역 구성 + 순수출. 국내산 비중 최소 5% |
| 투자 | 투자율 = 2023년 총자본형성 비율 (중국 41%라 상한을 35% → 50%로). 투자 바구니 = 기계·반도체·금속 + 건설(투자의 40% 이상) |
| 무역 수지 | 고정 이전 (Dekle·Eaton·Kortum 2007) |
| 탄력성 | v1 값(Ossa 보정)을 대응 물품에 옮김 (`src/v2/sectors.ts`) |
| 자료 생성 | `npm run production:v2` (World Bank, 18회, 22KB) → `npm run base:v2` → `src/data/v2-base-2023.json` |

확인한 것 (`src/v2/v2.test.ts`): 시작점에서 지역 간 교역 49개가 자료와 같다(오차 1e-8), 현상 유지 16분기 동안 변화 없음, 중동의 대한국 에너지 금수 → 한국이 나머지 세계·미국으로 공급처를 바꾸고 생활수준 −0.6%, 미국의 대중국 반도체 금수 → 중국이 대만·한국산으로 옮김(무역 전환), 미국의 대중국 50% 관세 → 미국의 대중국 수입 634 → 285(10억 달러), 다른 나라에서 수입 증가. 계산은 분기당 약 25ms.

연구 설계에 중요한 성질: 실질 GDP는 관세에 거의 반응하지 않는다. AI 6개국이 서로 100% 관세를 16분기 유지해도 GDP는 −0.1~−0.4%(대만 −2.1%)인데, 한국이 투자율을 5%p 올리면 16분기 뒤 GDP +1.3%다. 상대 이익 목표를 GDP 비율로 두면 관세보다 투자가 훨씬 강한 수단이 된다 (v1에서 AI들이 투자만 움직인 것과 같은 구조). 목표 정의는 다음 단계에서 다시 본다.

알려진 한계 (추가): 대만의 무역 흑자가 실제의 약 두 배다(블록 간 교역은 수입국 신고, 나머지 세계와의 교역은 자기 신고라 기준이 섞임). 홍콩·마카오가 신고한 수입은 중국의 원산지 기준 수입과 겹쳐 뺐다(약 1,480억 달러). 북한·시리아·예멘의 생산 구조는 같은 블록 평균, 대만·나머지 세계는 제조업 구성 자료가 없어 물품 전체를 한 묶음으로 나눴다.

## 게임 층 (2026-11-05, `src/v2/sim/`, `src/v2/diplomacy.ts`, `objectives.ts`, `culture.ts`, `policy.ts`)

| 항목 | 내용 |
|---|---|
| 분기 흐름 | v1과 같다. 1라운드 외교(6개국 동시) → 2라운드 수락·마지막 메시지·정책 결정(동시) → 약속 준수 확인 → 엔진 |
| 목표 | 절대 이익: 생활수준 분기 평균 + 0.3 × (임기 말 자본 − 100). 0.3은 v2 엔진으로 다시 잼 (자본 +1% → 다음 16분기 생활수준 +0.295~0.314). 상대 이익: 임기 말 명목 GDP 비율. 시작 값 한국 5.8%, 중국 58.9%, 일본 13.8%, 중동 11.4%, 미국 169.8%(비교 대상 중국), 대만 2.4% |
| 메시지 | 공개 성명(모두가 봄) + 비공개 메시지(받는 나라만 봄), 어조 표시. 라운드마다 |
| 제안 | 받는 나라 1곳 이상 지정. 받은 나라들이 동시에 수락 여부를 정하고, 수락한 나라 + 제안국끼리만 묶인다. 의무국: 제안국 / 수락국 / 참가국 모두. 의무는 다른 참가국에 대한 관세·수출 통제 상한. 참가국이 아닌 나라에 대한 정책은 묶이지 않는다 (차별적 블록 형성 가능). 제안은 당사국만 보고, 성립한 약속과 위반은 모두 공개 |
| 정책 | 상대 AI 5개국 × 교역재 10개의 관세(0~200%)와 수출 통제(0~3) + 투자율(10~50%). 매 분기 전체를 다시 쓴다(v1과 같음). 나머지 세계와의 정책은 고정. 0.1%p 단위로 적용 (시작 관세·투자율도 0.1%p로 반올림해, 현재 값을 그대로 쓰면 정책이 정확히 같다) |
| 나라 이름 조건 | 실제 이름 / A~F. 나라에만 적용, 물품 이름과 경제 수치는 둘 다 실제. JSON 키는 두 조건 모두 A~F와 영어 물품 키. 익명 조건 프롬프트에 실제 나라 이름이 없음을 테스트로 확인 |
| 문화 조건 | 있음: Hofstede 6개 지표 값(블록은 인구 가중 평균)과 중립적 정의. 없음: 문화 절 전체 생략 |
| 관측 | 7개 지역 상황표(생활수준·실질/명목 GDP·명목 GDP 비율·자본·물가·투자율·필수재 부족), 7×7 평균 관세 행렬, 모든 수출 통제, 우리 관세·상대국 관세(물품 × 상대국), 우리 수출·수입(물품 × 상대국), 각국 물품별 총수출, 최근 8분기 기록, 약속(지금 값과 준수 여부), 위반, 볼 수 있는 메시지. 2라운드에는 받은 제안, 우리가 보낸 제안, 현재 정책 JSON(출력 형식 그대로) |
| 확전점수 | 지도자에게 보여 주지 않는다. 게임 중에 계산하지 않고, 기록(분기별 정책 변화 목록, 메시지, 약속)에서 사후에 "누가 누구에게"로 잰다 (다음 단계) |
| 실제 변화 알려주기 | v1과 같은 조건. 켜면 지난 분기 우리나라가 실제로 바꾼 정책(상대국·물품별)을 보여 준다 |
| 규칙 지도자 | 현상 유지, 자유무역(1년마다 5개국 모두에게 상호 무관세 제안, 모든 제안 수락), 팃포탯(상대국마다 따로, 2023년 대비 변화를 따라 함. 상대가 통제를 걸면 그 나라로 가는 최대 수출품에 같은 단계) |

확인한 것 (`src/v2/sim/sim.test.ts`, 유료 호출 없음): 현상 유지 6개국 1년 동안 정책 변화·이상 기록 없음, 다자 제안에서 수락한 나라끼리만 묶이고 비참가국에 대한 관세 인상은 위반이 아님, 비공개 메시지는 받는 나라만 봄, 팃포탯이 상대국별로 따로 반응, 자유무역 6개국이 첫 분기에 모두 0% 관세, 가짜 LLM 응답으로 메시지·제안·정책·실제 변화 알려주기가 기록됨.

규칙 지도자 16분기 (모든 목표 같은 조건): 현상 유지와 팃포탯(먼저 움직이는 나라가 없으면)은 변화 없음. 자유무역은 절대 이익 점수 중국 100.27, 일본 100.06, 중동 100.03, 한국·미국 100.00, 대만 99.97. 명목 GDP 비율은 중국 58.9 → 60.2%, 미국 169.8 → 166.2%, 한국 5.80 → 5.78%.

프롬프트 길이: 시스템 약 5,400자 + 응답 형식(외교 1,600자, 결정 7,300자). 관측은 가짜 응답 한 판(2026-11-05)에서 1라운드 평균 약 7,000자, 2라운드 약 9,000자(받은 제안과 현재 정책 JSON 포함)로 재었고, 실제 메시지가 길어지는 몫(v1 Haiku 메시지 평균 250자)을 호출당 6,000자로 더해 추정한다 (아래 '측정과 실험 실행기').

## 바뀌는 코드

1. 엔진: 나라 N개 + 나머지 세계, 상대국별 관세·통제, N개국 시장 균형(Armington), 실제 데이터 보정
2. 지도자 프롬프트: 나라 이름 조건, 6개국 상황표, 상대국별 정책표, 다자 외교
3. 약속·위반: 의무 나라와 대상 나라
4. 측정: 확전·보복·호응을 "누가 누구에게"로. 자기 인식·결과 인식은 그대로 쓴다
